### Projeto em destaque — ReviewIt

Plataforma de resenhas em formato de feed social, meu projeto atual, construído do zero como estudo aplicado de arquitetura backend e boas práticas de produto:

- **Feed global** de resenhas (livros, filmes, álbuns), com filtros combináveis por gênero e tipo de conteúdo, busca por título e scroll infinito.
- **API REST em Spring Boot**, com arquitetura em camadas (Controller → Service → Repository → Entity), DTOs dedicados e tratamento centralizado de exceções.
- **Autenticação via OAuth** (Google/GitHub) com Supabase Auth, validação de JWT no backend via Spring Security (OAuth2 Resource Server).
- **Curtidas, comentários e sistema de moderação** com papéis de usuário (comum, moderador, admin) e ações de denúncia/advertência/suspensão/banimento.
- **Atualização em tempo real** do feed via Supabase Realtime.
- Documentação de **requisitos, user stories e diagramas de arquitetura** produzida antes da implementação — processo orientado a planejamento, não só código.
